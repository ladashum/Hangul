Вежливая форма настоящего времени

Самая частая форма в разговоре. Добавляем -아요 / -어요 / -여요 к основе глагола.

1. Основа на ㅏ или ㅗ → -아요
Если последняя гласная основы — ㅏ или ㅗ
가다 → 가요
идти · gada → gayo
보다 → 봐요
смотреть · boda → bwayo
만나다 → 만나요
встречать · mannada → mannayo
2. Остальные гласные → -어요
Если последняя гласная — ㅓ, ㅜ, ㅡ, ㅣ и т.д.
먹다 → 먹어요
есть · meokda → meogeoyo
읽다 → 읽어요
читать · ikda → ilgeoyo
배우다 → 배워요
учить · baeuda → baewoyo
3. Глаголы на 하다 → -해요
하다 и все глаголы на -하다 меняются в -해요
하다 → 해요
делать · hada → haeyo
공부하다 → 공부해요
учиться · gongbuhada → gongbuhaeyo
좋아하다 → 좋아해요
любить · joahada → joahaeyo

Словарьная форма → вежливое настоящее. Нажми 🔊

Прошедшее и будущее

Те же правила гласных, только другие окончания.

Прошедшее: -았어요 / -었어요 / -였어요
Те же правила, что и для настоящего, но с 았/었.
가다 → 갔어요
ходил(а) · gasseoyo
먹다 → 먹었어요
ел(а) · meogeosseoyo
하다 → 했어요
делал(а) · haesseoyo
Будущее / намерение: -을 거예요 / -ㄹ 거예요
После согласной — 을 거예요, после гласной — ㄹ 거예요.
가다 → 갈 거예요
пойду · gal geoyeyo
먹다 → 먹을 거예요
буду есть · meogeul geoyeyo
공부하다 → 공부할 거예요
буду учиться · gongbuhal geoyeyo
Отрицание: 안 + глагол
Самый простой способ сказать «не».
안 가요
не иду · an gayo
안 먹어요
не ем · an meogeoyo
안 해요
не делаю · an haeyo
